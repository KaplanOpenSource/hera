Welcome to Hera Documentation
=============================

Hera is a comprehensive toolkit for atmospheric dispersion modeling, risk assessment,
and environmental analysis. This documentation is organized into two main sections:

- **User Documentation**: Practical guides, tutorials, and examples for using Hera
- **Developer Documentation**: Complete API reference and implementation details
